# Инструменты проверки проекта

Для форматирования и проверки кода используются Prettier, Stylelint и html-validate.

## Первый запуск

1. Установи Node.js LTS: https://nodejs.org/
2. Открой терминал VS Code в корневой папке проекта.
3. Выполни:

   ```bash
   npm install
   ```

## Команды

- `npm run format:check` — проверить форматирование без изменения файлов.
- `npm run format` — автоматически отформатировать HTML, CSS, JavaScript, Markdown и JSON.
- `npm run lint:css` — проверить CSS на типичные ошибки и несогласованный стиль.
- `npm run lint:html` — проверить HTML-разметку.
- `npm run check` — выполнить все проверки по очереди.

## Важно

Первый запуск проверок может показать замечания в старом коде. Это ожидаемо: линтеры нужны не для того, чтобы скрыть предупреждения, а чтобы найти их и исправлять постепенно.

Перед `npm run format` сохрани копию проекта или сделай Git-коммит. Prettier меняет форматирование файлов, но не должен менять их поведение.
