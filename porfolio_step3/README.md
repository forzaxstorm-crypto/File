# Ростислав — Frontend-портфолио

Личное портфолио с учебными проектами и примерами практики на HTML, CSS и JavaScript.

**Сайт:** https://forzaxstorm-crypto.github.io/portfolio/  
**GitHub:** https://github.com/forzaxstorm-crypto

## Что изучаю и практикую

- HTML5 — семантическая разметка и структура страниц
- CSS3 — стилизация, адаптивная вёрстка и анимации
- JavaScript — DOM, события, формы и простая клиентская логика
- Git и GitHub — хранение кода и публикация проектов

## Учебные проекты

Все проекты ниже созданы для практики. Это не коммерческие заказы.

- **Coffee House** — сайт кофейни: `coffee.html`
- **Gaming Store** — учебный каталог игровых товаров с корзиной: `gaming.html`
- **NOVA GROUP** — концепт сайта архитектурной компании: `company.html`

## Небольшие задачи, которые могу брать

- простая адаптивная HTML/CSS-вёрстка;
- небольшие Landing Page по готовому макету или понятному ТЗ;
- исправление небольших CSS-ошибок;
- правки структуры и контента существующей страницы.

Сложную backend-разработку, Laravel, PHP, WordPress и базы данных пока не предлагаю.

## Форма заявки

Форма на главной странице отправляет имя и текст заявки через Formspree. Endpoint хранится в `main.js`; адрес получателя настраивается в аккаунте Formspree и не публикуется в исходном коде. Чтобы получить ответ, посетителю нужно оставить удобный способ связи в тексте сообщения.
## Структура и поддержка стилей

- Главная страница использует `styles.css` с CSS Cascade Layers (`@layer`).
- У каждой учебной страницы свой файл стилей: `coffee.css`, `gaming.css`, `company.css`.
- Повторения селекторов внутри медиазапросов используются для адаптивных состояний и не являются автоматической ошибкой.
- В ходе ревизии объединены несколько дублирующих базовых правил `.hero` в Gaming Store и поздние базовые переопределения `.header` / `.portfolio-link` в NOVA GROUP.
